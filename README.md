# Friend Checker in Java

A simple Java console application that checks whether a user is present in a predefined friends list.

## Features

- Takes user input from the keyboard
- Searches for the name in an array of friends
- Displays whether the person is a friend or not
- Uses loops, arrays, boolean variables, and string comparison

## Technologies Used

- Java
- IntelliJ IDEA (or any Java IDE)

## How It Works

1. The program asks the user to enter a name.
2. It compares the entered name with names stored in a friends array.
3. If a match is found, it displays:
   ```
   Ap Tushar ke dost ho!
   ```
4. Otherwise, it displays:
   ```
   Ap Tushar ke dost nahi ho!
   ```
